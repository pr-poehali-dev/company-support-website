# 📧 Пошаговая инструкция: Настройка Mail.ru для отправки писем с сайта

## 🎯 Что нужно сделать?

1. Получить пароль приложения в Mail.ru
2. Установить PHPMailer на хостинг
3. Настроить файл send-email.php
4. Загрузить на хостинг и протестировать

---

## 📝 Шаг 1: Получаем пароль приложения Mail.ru

⚠️ **ВАЖНО:** Обычный пароль от почты НЕ РАБОТАЕТ! Нужен специальный "пароль приложения".

### Инструкция:

1. **Войдите в Mail.ru**
   - Перейдите: https://mail.ru
   - Войдите в свой почтовый ящик (например: `info@mail.ru`)

2. **Включите двухфакторную аутентификацию** (если ещё не включена)
   - Нажмите на своё имя в правом верхнем углу
   - Выберите **"Настройки"** → **"Безопасность"**
   - Найдите раздел **"Двухфакторная аутентификация"**
   - Нажмите **"Включить"** и следуйте инструкциям
   - Привяжите телефон для получения SMS-кодов

3. **Создайте пароль для внешних приложений**
   - В том же разделе "Безопасность" прокрутите ниже
   - Найдите **"Пароли для внешних приложений"**
   - Нажмите **"Добавить"**
   - Введите название: `Glavbuhvl Website` (или любое другое)
   - Нажмите **"Создать"**
   - **ВАЖНО:** Скопируйте показанный пароль! Он больше не появится!
   - Сохраните его в блокноте

### Пример пароля приложения:
```
abcd1234efgh5678ijkl
```
Это НЕ ваш обычный пароль от почты!

## 🔧 Шаг 2: Скачиваем и устанавливаем PHPMailer

### Способ A: Вручную (рекомендуется)

1. **Скачайте PHPMailer:**
   - Перейдите: https://github.com/PHPMailer/PHPMailer/releases
   - Нажмите на последнюю версию (например: `6.9.1`)
   - Скачайте файл `PHPMailer-6.9.1.zip`

2. **Распакуйте архив:**
   - Откройте скачанный ZIP-файл
   - Найдите папку `src/`
   - Внутри будет 3 файла:
     - `PHPMailer.php`
     - `SMTP.php`
     - `Exception.php`

3. **Создайте структуру на компьютере:**
   ```
   Создайте папку: PHPMailer/
   Скопируйте туда эти 3 файла
   ```

4. **Загрузите на хостинг:**
   - Откройте FTP-клиент (FileZilla, Total Commander) или панель хостинга
   - Перейдите в корневую папку сайта (обычно `/public_html/` или `/www/`)
   - Загрузите папку `PHPMailer/` туда же, где лежит `send-email.php`

### Способ B: Через Composer (если доступен на хостинге)

```bash
cd /path/to/your/public_html
composer require phpmailer/phpmailer
```

Затем в `send-email.php` замените строку подключения:
```php
require_once 'vendor/autoload.php';
```

## ⚙️ Шаг 3: Настраиваем send-email.php

1. **Откройте файл `send-email.php`** (из папки `public/`)

2. **Найдите раздел конфигурации** (в самом начале файла):

```php
// Конфигурация email
define('EMAIL_HOST', 'smtp.yandex.ru');
define('EMAIL_PORT', 465);
define('EMAIL_USER', 'info@glavbuhvl.ru');
define('EMAIL_PASSWORD', 'your_app_password');
define('EMAIL_TO', 'lore07061994@gmail.com');
```

3. **Замените на настройки Mail.ru:**

```php
// Конфигурация email для Mail.ru
define('EMAIL_HOST', 'smtp.mail.ru');
define('EMAIL_PORT', 465);
define('EMAIL_USER', 'ваша-почта@mail.ru'); // Замените!
define('EMAIL_PASSWORD', 'abcd1234efgh5678ijkl'); // Вставьте пароль приложения из Шага 1!
define('EMAIL_TO', 'lore07061994@gmail.com'); // Куда приходят заявки
```

### 📋 Пример для вашего случая:

Если у вас почта `info@glavbuhvl.ru` на Mail.ru:

```php
define('EMAIL_HOST', 'smtp.mail.ru');
define('EMAIL_PORT', 465);
define('EMAIL_USER', 'info@glavbuhvl.ru');
define('EMAIL_PASSWORD', 'abcd1234efgh5678ijkl'); // Сюда пароль из Шага 1
define('EMAIL_TO', 'lore07061994@gmail.com');
```

⚠️ **EMAIL_USER должен совпадать с почтой, от которой получили пароль приложения!**

4. **Сохраните файл**

## ❌ Решение проблем

### Ошибка: "SMTP connect() failed"

**Причина:** Хостинг блокирует подключения к SMTP

**Решение:**
1. Попробуйте изменить порт на `587`:
```php
define('EMAIL_PORT', 587);
```

2. Свяжитесь с техподдержкой хостинга и спросите:
   - "Разрешены ли исходящие SMTP-подключения?"
   - "Какие порты открыты: 465, 587, 25?"

### Ошибка: "Invalid address" или "Authentication failed"

**Причина:** Неправильный пароль или email

**Решение:**
1. Убедитесь, что `EMAIL_USER` совпадает с почтой Mail.ru
2. Убедитесь, что используете **пароль приложения**, а не обычный пароль
3. Попробуйте создать новый пароль приложения
4. Проверьте, нет ли пробелов в пароле

### Ошибка: "Could not instantiate mail function"

**Причина:** PHPMailer не найден

**Решение:**
1. Проверьте, что папка `PHPMailer/` загружена на хостинг
2. Убедитесь, что в `send-email.php` правильный путь:
```php
require_once 'PHPMailer/PHPMailer.php';
require_once 'PHPMailer/SMTP.php';
require_once 'PHPMailer/Exception.php';
```

### Письма попадают в спам

**Решение:**
1. Используйте email с вашего домена: `info@glavbuhvl.ru` (не @mail.ru)
2. Настройте SPF-запись для домена:
   - Зайдите в панель управления доменом
   - Добавьте TXT-запись:
   ```
   v=spf1 include:_spf.mail.ru ~all
   ```

## 📞 Если всё равно не работает

1. **Проверьте логи ошибок PHP:**
   - В cPanel: "Логи" → "Логи ошибок"
   - В ISPmanager: "Журналы" → "Журнал ошибок веб-сервера"

2. **Проверьте права доступа к файлам:**
   - `send-email.php` должен иметь права `644`
   - Папка `PHPMailer/` должна иметь права `755`

3. **Свяжитесь с хостером:**
   - Спросите: "Разрешены ли SMTP-подключения на портах 465 и 587?"
   - Попросите проверить логи, если отправка не работает

4. **Попробуйте альтернативу:**
   - Используйте Яндекс.Почту вместо Mail.ru
   - Или Gmail (если есть аккаунт)
